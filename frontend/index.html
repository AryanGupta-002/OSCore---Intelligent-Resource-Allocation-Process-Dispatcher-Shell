What is OSCore?

OSCore is an operating system simulation and resource-management testbed designed to demonstrate how processes compete for CPU time, memory and I/O devices. It brings process dispatching, scheduling, memory allocation and finite-resource management into one interactive environment. Users can load a workload, execute it through the HOST dispatcher or run individual scheduling algorithms, and observe how different policies affect process execution. The platform also records simulation results in PostgreSQL, making it possible to inspect execution history, compare performance metrics and understand the decisions made by the simulated operating system.

WORKLOAD FORMAT

What does a job file contain?

Each CSV row represents one process. The workload describes when a process arrives, how much CPU time it needs, its priority, memory requirement and the I/O devices it requests. OSCore uses these values to initialise the simulation and evaluate whether the selected testbed can admit and execute each process.
